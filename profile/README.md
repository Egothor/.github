# Egothor

**Research-driven engineering for secure and regulated information systems.**

Since 1998, Egothor has turned research questions into practical software. Our work spans search, software assurance, cryptography and language technology, with authorization, integrity and operational constraints built into the design.

### What we work on

- **Information retrieval** — search systems that respect authorization and information boundaries throughout retrieval and disclosure.
- **Software assurance** — reproducible test inventories, security classification and evidence for regulated software delivery.
- **Cryptographic systems** — classical and post-quantum cryptography for secure data, PKI and resilient offline workflows.
- **Language and infrastructure** — high-performance multilingual stemming and lightweight components for decoupled Java systems.

### How we build

We favour explicit models, deterministic behaviour and lean runtime paths. Reproducibility, traceability and reviewable evidence help people understand, operate and trust the systems we build.
